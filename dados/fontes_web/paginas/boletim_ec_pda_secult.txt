1. Introdução




                                                                                                      09/11/2022 15:41
O Plano de Dados Abertos (PDA) é o instrumento que operacionaliza a Política de Dados Abertos
do Poder Executivo Estadual, pois auxilia o planejamento das ações que visam a abertura e
sustentação de dados nas organizações públicas.

Este plano contém, de forma detalhada, as ações de implementação e promoção de abertura

de dados deste órgão/entidade. Contém os responsáveis pela implantação, as bases de dados
que serão priorizadas para abertura à sociedade e o cronograma de disponibilização dos dados.

Este documento baseia-se na Política de Dados Abertos do Estado do Espírito Santo,
estabelecida pelo Decreto nº 5139-R/2022. Será revisado a cada dois anos e publicado no sítio
institucional para divulgação à sociedade.
