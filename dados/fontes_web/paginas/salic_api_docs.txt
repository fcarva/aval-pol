SALIC API

Essa é uma API aberta para acesso aos dados do portal 
SALIC
.

SALIC é um sistema que reúne dados a respeito de propostas de projetos culturais a serem incentivados pelo Ministério da Cultura (MINC) por meio da lei Rouanet.

Veja mais informações 
aqui
.

Formatos de Resposta

Atualmente a API suporta exportação dos dados nos formatos 
 HAL+JSON(padrão) 

 XML e 
 CSV. A escolha do formato deve ser definido a cada chamada, por meio do campo de cabeçalho Accept ou pelo parâmetro de pesquisa format.

Paginação

Para alguns recursos que possam gerar um grande volume de resultados, a API provê um sistema de paginação. Ao fazer sua requisição, basta fazer uso dos campos limit [1-100] e offset [0-Total-Count] para navegar pelos resultados. Você também pode se guiar pelos links first, self, prev, next, last contidos nas respostas. Sua resposta conterá campos count e total que se referem ao total de objetos retornados e total de entradas contidas na base de dados repectivamente. Adicionamente, um campo de cabeçalho chamado X-Total-Count será enviado junto às respostas, denotando também o total de entradas contidas na base de dados que atendam ao seu critério de busca.

Authenticating requests

This API is not authenticated.
